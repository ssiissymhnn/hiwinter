# HI WINTER

> 시즌을 기다리는 가장 즐거운 방법

스노보드 시즌 준비 플랫폼 앱의 인터랙티브 프로토타입입니다.
시즌권 비교, 가상 피팅, 라이딩 메이트·시즌방 모집, 중고 거래까지 — 여러 곳에 흩어져 있던 시즌 준비 과정을 하나의 앱으로 모았습니다.

HTML · CSS · Vanilla JavaScript만 사용했고, 프레임워크·빌드 도구·외부 의존성이 없습니다.

---

## 실행

별도 설치 없이 `index.html`을 브라우저로 열면 됩니다.

```bash
git clone https://github.com/ssiissymhnn/hiwinter.git
cd hiwinter
open index.html          # macOS
# 또는 로컬 서버
python3 -m http.server 8000
```

iPhone 16 화면(393 × 852)을 기준으로 디자인했습니다. 데스크톱에서는 기기 프레임 안에, 모바일에서는 전체 화면으로 표시됩니다.

### GitHub Pages

Settings → Pages → Source를 `main` 브랜치 루트로 지정하면 바로 배포됩니다.

### URL 파라미터

개발·시연용 파라미터를 지원합니다.

| 파라미터 | 설명 |
|---|---|
| `?intro=1` | 가입 완료 상태여도 온보딩을 처음부터 다시 보기 |
| `?skipIntro=1` | 온보딩 건너뛰고 바로 홈으로 |
| `?screen=plan` | 특정 화면으로 바로 진입 (`home`/`plan`/`outfit`/`community`/`my` 또는 라우트명) |
| `?key=5A79DB` | 키컬러를 바꿔서 확인 |

## 주요 기능

**1. 시즌권 비교 · 베이스 스키장 D-day** (PLAN)
리조트별 시즌권 가격·혜택·얼리버드 마감을 한 화면에서 비교하고, 등록한 스키장의 개장일까지 남은 날을 홈에서 확인합니다. 시즌 준비 체크리스트로 진행률을 관리합니다.

**2. AI 가상 피팅** (OUTFIT)
내 사진에 자켓·팬츠·고글·헬멧·장갑을 입혀보고 마음에 드는 코디를 저장합니다.
*프로토타입에서는 실제 AI 모델 대신 로딩 연출과 결과 화면으로 플로우를 재현합니다.*

**3. 라이딩 메이트 · 시즌방 모집** (COMMUNITY)
스키장·날짜·실력·인원, 위치·기간·성별·비용이 정해진 칸으로 입력되는 양식형 모집 글. 카페나 오픈채팅의 비정형 글을 구조화했습니다.

**4. 장비·웨어 중고 마켓** (MARKET)
스노보드 카테고리에 맞춘 중고 거래. 커뮤니티 안에서 진입하며, 진입 시 배경이 어두워져 다른 영역과 구분됩니다.

그 외 — 대회 일정(다가오는 대회 / 지난 대회 결과), 통합 검색, 관심 대회·찜·저장 글 관리.

## 폴더 구조

```
hiwinter/
├── index.html      앱 셸 (상태바 · 화면 스택 · 탭바 · 오버레이 호스트)
├── style.css       디자인 토큰 + 전체 컴포넌트 스타일
├── script.js       라우터 · 뷰 · 상태 · 아이콘 · 이미지 데이터
└── assets/images/  원본 이미지 (참고용)
    ├── logo-hi-winter.png
    ├── home-image.png / .webp     홈 캐릭터
    ├── intro/                     온보딩 스플래시
    ├── resort/                    스키장 전경 6 + 슬로프맵 6
    ├── house/                     시즌방 사진
    └── market/                    마켓 상품 사진 10
```

> **참고** — `assets/images/`는 원본 보관용입니다.
> 앱은 단일 파일로 동작하도록 이미지를 `script.js` 안에 data URI로 내장하고 있어서, 이미지를 교체하려면 `script.js` 상단의 `RESORT_IMG` · `RESORT_MAP` · `HOUSE_IMG` · `PRODUCT_IMG` · `HERO_IMG` · `SPLASH_IMG` 상수를 바꿔야 합니다. 실제 서비스로 옮길 때는 내장 대신 파일 참조로 바꾸는 편이 좋습니다.

### script.js 구성

1. 유틸리티 (`$`, `esc`, `won` …)
2. 테마 엔진 — 키컬러 하나로 16개 이상의 CSS 변수를 HSL 연산으로 파생 (`setTheme`)
3. 아이콘 시스템 — `currentColor` 기반 인라인 SVG 59종 (`ic`)
4. 이미지 상수 — 로고 마스크, 스키장, 시즌방, 마켓, 홈, 스플래시
5. 데이터 — 스키장 6, 게시글 12, 상품 10, 대회 9, 체크리스트, 아이템
6. 상태 저장소 — `localStorage` (`hiwinter.v2`)
7. 셸 — 토스트 · 바텀시트 · 히스토리 스택 라우터
8. 뷰 28종 — 각 뷰는 HTML 문자열을 반환하는 함수
9. 액션 핸들러 — `data-act` 위임 처리
10. 온보딩 — 스플래시 → 슬라이드 3 → 로그인/가입 → 프로필 설정

## 데이터에 대하여

프로토타입이므로 백엔드가 없고, 모든 상태는 브라우저 `localStorage`에 저장됩니다.
설정 → "저장된 데이터 초기화"로 처음 상태로 되돌릴 수 있습니다.

등장하는 **브랜드명·상품명·대회명·주최사·인물명은 모두 가상**입니다. 대회 일정과 입상자 기록도 샘플 데이터이며 실제 대회가 아닙니다. 스키장 이름과 슬로프맵만 실제 정보를 참고했습니다.
